# BrewHaus Practicum, Week 1 Assignment, Travel Agency

This project is a responsive travel agency landing page created as part of the BrewHaus Practicum. The website is built using plain HTML and CSS and includes a modern layout with sections for travel highlights, package offers, testimonials, and contact details.

## Project files
- `index.html` — page structure and content
- `style.css` — layout, styling, and responsive design

## Run locally
Open `index.html` in a browser to view the website.

## Assignment focus
- One-page travel website design
- Semantic HTML structure
- Responsive layout with Flexbox and Grid
- Clean styling with CSS variables
- Mobile-friendly design
